## 二、接口设计

```python
# 元数据只读结构
VibrationMeta(
    path, channel, sample_rate_hz, sample_count, started_at,
    device_ip, site, rule, format_version, scale,
)  # 属性 duration_s

VibrationRecord(meta, samples: ndarray[float32])  # 属性 duration_s / time_axis() / to_frame()

read_vibration_header(path) -> VibrationMeta     # 只读 512 B，不加载数据体（批量索引/巡检用）
read_vibration(path) -> VibrationRecord          # 读全量，校验长度一致性
scan_vibration_dir(dir) -> list[VibrationMeta]   # 目录批量索引，按开始时间升序
VibrationFormatError(ValueError)                # 格式/长度异常
```

设计约束：
1. 不猜测单位，`unit` 不做硬编码；幅值为设备原始标度，`scale` 从头部透出供后续标定。
2. 长度为唯一真相：`512 + 4*sample_count` 必须等于文件长度，否则报错（避免静默截断）。
3. 头部不合法（版本不在支持集合）直接报错，不做"尽力而为"解析。
4. 用 `np.memmap` 支持大文件切片，但对外返回只读数组。

## 三、TDD 垂直切片顺序

| # | 行为 | 断言要点 |
|---|---|---|
| 1 | 读头部元数据 | fs/count/channel/时间解析正确，不读数据体 |
| 2 | 读全量样本 | 样本值与写入值逐元素相等，dtype=float32 |
| 3 | 长度不一致报错 | 截断文件 → `VibrationFormatError` |
| 4 | 版本不支持报错 | 篡改版本号 → `VibrationFormatError` |
| 5 | 时间轴与时长 | `duration_s == count/fs`，`time_axis()` 首末值正确 |
| 6 | 目录批量扫描 | 只收 `.dat`，按时间升序，返回 Meta 列表 |
| 7 | 真实样本集成测试 | 现场文件 fs=32000、count=320000、时长 10 s，文件不存在则 skip |
