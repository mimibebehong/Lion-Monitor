# P2 取数按节点（S1）

## 目标
同一采集通道挂到多个监测对象时，趋势 / 健康评级 / 超限记录 / CSV **不再串值**。

## 依据
- `docs/reviews/2026-10-31-总体复查.md` 问题 S1（同通道多节点串值）+ Q1 拍板：**允许**同一通道号挂多个监测对象
- 现状：`store/metrics.list_values()` 已支持 `node_id` 入参（S3-A 已落库按节点存），但 trends / health / overview 仍在按通道号取全部

## 要做的事
1. `app/pages/trends.py`：取数一律带 `node_id`；趋势按 (通道, 节点, 指标) 出图，不把同通道其它节点的点混进来。
2. 健康评级 / 工作台概览 / 超限记录计数：同样按 `node_id` 过滤，评级用该节点生效阈值。
3. CSV 导出增加「监测对象」列（没有节点归属的老数据留空，不许报错）。
4. 兼容性：老数据 `node_id` 为空时行为与现在一致（不得报错、不得丢点）。

## 验收标准（必须逐条实测）
- 造「同一通道 CH1 挂两个监测对象」的数据（各 3 个指标点）：
  - 趋势页选对象 A → **3 个点**（不是 6 个）；对象 B → 3 个点
  - 超限记录按对象计数 → A 为 3、B 为 3（不是 6）
  - 两个对象阈值不同时 → 评级各自按自己的阈值判
- CSV 含「监测对象」列且值正确。
- 全量 `pytest` 全绿（新增用例覆盖上述）。
