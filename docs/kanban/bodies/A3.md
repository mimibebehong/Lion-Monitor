数据分析 · A3：包络谱（带通 + 希尔伯特 + 去均值 + 标记 + CSV）

## 目标
接通「③ 包络谱」页签。链路：带通（巴特沃斯，阶数可调，默认 0~fs/2）→ 希尔伯特取模得包络 →
去均值（默认勾选）→ FFT → 画包络谱 → 目标频率/阶次标记线 → CSV 导出。
包络方法固定希尔伯特，界面不给选择（已定）。带通上限 ≤ 下限时给出告警且不计算。

## 验收标准
- 合成调幅信号（载波 5 kHz、调制 25 Hz、32 kHz 采样）：包络谱主峰 = 25 Hz，误差 < 1 个 bin。
- 去均值生效：不勾选时 0 Hz 处有直流峰，勾选后该峰消失，且 25 Hz 峰幅值不变（单测断言两者相等）。
- 带通参数非法（上限 ≤ 下限）时抛错/给出提示，不产生 NaN 图。
- CSV 导出含 频率, 幅值 两列。
- 真实数据实测：`DS-20261029-002` CH2，2–10 kHz 带通，包络谱应出现 145 Hz 与 290 Hz 的两条线。
