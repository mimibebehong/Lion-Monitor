## 背景（马哥 2026-11-02 定）
「不足指标计算窗口的数据直接判无效」。当前实现（S4W-1/S4W-2 引入）是「整段短于一窗时整段当 1 个窗」，会给 1~63 点这种无效样本算出 0 值。

## 目标
1. 撤销「整段短于一窗当 1 个窗」的兜底：样本点数 `n < window_s × fs` → **该指标不出值**，判定为无效并记录原因。
2. 原因文案要具体：`样本 32 点，不足一窗（2 s @ 32000 Hz 需 64000 点）`。写入：
   - 导入结果/批次详情（`ImportResult` 里可加 `skipped_short` 明细，或在超限/跳过记录结构里带原因）
   - 页面提示（导入结果区）与日志（`logs/lion-monitor.log`）。
3. `window_s` 取该节点生效参数（含默认 2 s）；包络谱等有独立窗长参数的按各自生效值判断。
4. 边界：`n == window_s×fs` 恰好一窗 → **有效**；`n < 1` → 无效。
5. 同步更新受影响测试（原先断言「短于一窗给 1 个值」的用例改为断言「不出值 + 有原因」），报告里列出。
