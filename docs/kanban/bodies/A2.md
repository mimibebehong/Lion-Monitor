数据分析 · A2：FFT 频谱（去均值 + 窗函数 + Peak/RMS + 主峰 + 标记线 + CSV）

## 目标
接通「② FFT 频谱」页签：对选中区间做整段一次 FFT。
参数：窗函数（汉宁/平顶/海明/布莱克曼/凯泽/矩形）、幅值类型（峰值 Peak / 有效值 RMS）、去均值（默认 True）。
显示：单边幅值谱（0~fs/2）、主峰用 ▲ 标注并列出前几个峰、目标频率竖线、阶次竖线（阶次基准 = 目标频率第一个值，n× 画在 n×f0）。

## 验收标准
- 合成 145 Hz、幅值 0.5 g 正弦（32 kHz、20 s）：主峰频率误差 < 1 个 bin，峰值误差 < 2%。
- 峰值 Peak / 有效值 RMS 换算：同一谱线两者比值 = √2（单测断言）。
- 加窗后幅值仍准确（窗函数相干增益归一），矩形窗与汉宁窗在同一正弦上峰值差异 < 2%。
- 阶次换算：目标频率 25 + 阶数 1,2,3 → 竖线位置 25/50/75 Hz（单测断言换算函数）。
- CSV 导出含 频率, 幅值 两列。
- 真实数据实测：`DS-20261029-002` CH2 主峰应在 145 Hz 附近（转频 1×）。
