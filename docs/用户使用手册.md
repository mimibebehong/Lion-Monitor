## 1. 这套软件做什么

Lion-Monitor 把产线采集回来的**振动原始数据（.dat）**变成可判读的设备健康结论：

```
采集目录(.dat)  →  导入为数据集  →  计算指标(v_RMS / a_Peak / a_RMS …)
                                              ↓
        健康树（任务 → 设备 → 监测对象 → 通道 → 指标）
                                              ↓
                     阈值判级（正常 / 预警 / 告警）→ 趋势与健康评级
```

特点：

- **单机部署，浏览器使用**。程序在本机跑一个本地服务（默认端口 8501），界面在 Edge / Chrome 里打开；
  同一台机器跑着，局域网内其他电脑也能用浏览器访问。
- **完全离线**。自带便携 Python 运行时，目标机器不需要装 Python，也不需要联网。
- **数据都在本机**。数据库是单个 SQLite 文件，备份就是拷一个文件。
- **按任务隔离**。监测对象、传感器、指标、阈值都挂在「当前测试任务」下，换任务互不影响。

## 2. 安装与卸载

### 2.1 系统要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / Windows 11，64 位（Windows Server 2022 也可） |
| 权限 | 安装需要管理员（注册防火墙规则；勾选开机自启时还要注册服务） |
| 磁盘 | 安装后约占 1 GB，建议预留 2 GB 以上（数据会持续增长） |
| 浏览器 | Microsoft Edge 或 Google Chrome（其他 Chromium 内核浏览器也可） |
| 网络 | **不需要联网**（安装包已含全部依赖） |

### 2.2 安装步骤

1. 双击 `LionMonitor-Setup-0.1.1.exe`，在系统弹窗（UAC）里点「是」。
2. **欢迎页**：点「下一步」。
3. **安装说明页**：读一下注意事项（端口 8501、数据目录、卸载保留数据），点「下一步」。
4. **选择目标位置**：默认是 `C:\LionMonitor`。
   - 想换盘：直接在输入框里改，例如 `D:\software\LionMonitor`；
   - 或者点右侧「浏览(R)...」选目录；
   - 路径可以带空格和中文，程序会正确处理。
5. **附加任务**：勾「创建桌面快捷方式」；如果希望**开机自动启动**（不需要登录就提供网页服务），
   再勾「开机自启（注册 Windows 服务）」。
6. **准备安装 → 安装**：安装器会自动完成
   - 复制程序与便携运行时；
   - 放行 8501 端口的防火墙规则；
   - 环境自检（依赖、目录权限、端口、浏览器、磁盘空间）；
   - 把演示数据里的文件路径改到本机安装目录；
   - 可选：注册开机自启服务。
7. **完成页**：说明怎么启动、日志在哪。勾选「立即运行」可直接打开。

> 自检若有失败项，安装结束时会弹窗列出「哪一项失败 + 怎么处理」，日志在 `<安装目录>\logs\selfcheck.log`。

### 2.3 启动方式

| 方式 | 操作 | 适用 |
|---|---|---|
| 桌面快捷方式 | 双击「Lion-Monitor」 | 日常使用（推荐） |
| 开始菜单 | 开始菜单 → Lion-Monitor → Lion-Monitor | 桌面没有图标时 |
| 免安装绿色包 | 双击 `dist\LionMonitor.exe` | 不想安装、放到 U 盘里用 |

启动器的工作过程：检查是否已有实例在跑 → 没有就起本地服务 → 等健康检查通过 → 自动打开浏览器。
**第二次双击只会再打开一个浏览器标签页，不会起第二个服务**，不会重复占端口。

启动大约需要 10–25 秒（第一次启动要解包缓存，稍慢），启动完成后浏览器会自动打开
`http://localhost:8501`。窗口出现前请稍等，不要连续双击。

### 2.4 局域网访问

同一网段的其他电脑，在浏览器里打开：

```
http://<本机 IP>:8501
```

本机 IP 可以在 `logs\selfcheck.log` 末尾的「局域网访问地址」里看到，或在命令行执行 `ipconfig`。
安装器已放行 8501 端口的入站规则（专用网络）。如果是域网络或公共网络，需要在
「Windows 安全中心 → 防火墙 → 允许应用通过防火墙」里再确认一次。

### 2.5 开机自启（可选）

安装时勾了「开机自启」就已经注册好了。之后想补装或修掉，用管理员身份打开命令提示符：

```bat
:: 注册并启动（路径换成你的安装目录）
D:\software\LionMonitor\installer\service_install.cmd "D:\software\LionMonitor" 8501

:: 停止并注销
D:\software\LionMonitor\installer\service_remove.cmd "D:\software\LionMonitor"
```

查看服务状态：`sc query LionMonitor`（`RUNNING` 即正常）。
服务模式不弹浏览器，适合当「产线内网小服务器」用。

### 2.6 停止

- 桌面快捷方式启动的实例：关闭启动器窗口，或双击 `stop.bat`；
- 服务方式：`sc stop LionMonitor`，或运行 `service_remove.cmd`。

### 2.7 卸载

控制面板 →「程序和功能」→「Lion-Monitor」→ 卸载，按向导确认即可。

**卸载只删程序文件**，以下目录默认保留，重装后数据还在：

- `<安装目录>\data`（数据库 + 原始数据）
- `<安装目录>\logs`（日志）
- `<安装目录>\backup`、`<安装目录>\data\backups`（备份）

需要彻底清空时，卸载后手动删除整个安装目录。

### 2.8 升级

直接运行新版本安装包，在「选择目标位置」里**填回原来的安装目录**（安装器每次都从默认目录开始，
不会记住上次路径）。数据库、日志、备份不会被覆盖，程序文件会被替换。

> 升级前建议先在「数据库备份」页点一次「立即备份数据库」。

### 3.1 左侧导航

| 分组 | 页面 | 一句话 |
|---|---|---|
| 总览 | 工作台 | 今天的活儿：任务概况、设备健康、待办 |
| 测试任务 | 任务列表 | 新建/切换/归档任务 |
| | 健康树配置 | 装配「设备 → 对象 → 通道 → 指标」并挂台账 |
| | 监测对象 | 对象台账、通道、特征频率参数 |
| | 传感器 | 传感器台账与归属 |
| | 指标配置 | 指标定义（算法 + 参数） |
| | 阈值设置 | warn / alert 阈值，支持继承 |
| 数据与分析 | 数据接入 | 扫描采集目录 → 导入 → 算指标 |
| | 趋势分析 | 指标曲线、判级、健康评级、重算 |
| | 数据集管理 | 数据集与通道文件明细、有效性、删除 |
| | 数据分析 | 单通道原始曲线 / FFT / 包络谱 |
| 系统 | 数据库备份 | 一键整库备份 |
| | 回收站 | 恢复或彻底删除已删对象 |

> 开始菜单里还有三个实用入口：「用户使用手册」（PDF）、
> 「Lion-Monitor 日志目录」、「收集诊断日志（发给技术支持）」。

### 3.2 三件必知的事

1. **所有配置都挂在「当前测试任务」下**。左侧顶部的下拉框是任务切换器；换任务后，
   监测对象、传感器、指标、阈值、树结构都会换成该任务自己的。
2. **页面右上角的提示**（绿色/黄色/红色条）告诉你上一步操作的结果，例如「已导入 3 个批次」。
   长提示可以点关闭。
3. **页面上带 ⓘ 的地方是操作提示**，鼠标悬停可看，不占版面。

### 3.3 页面切换的默认行为

点左侧导航进入某个页面时，**页面总是从它的默认状态开始**（不记得上次选中的树节点、展开状态、
筛选条件、页签）。只有「当前测试任务」会跨页面保留。

这条规则是为了避免「明明点了新页面，看着还停在旧内容」的错觉。

## 4. 五分钟跑通（演示数据）

发行版自带一套完整演示数据（任务 `TT-20261029-01 · 卷绕产线振动监测`，
4 个监测对象 / 4 个通道 / 3 个批次 / 12 个 `.dat` 文件）。

1. 打开浏览器 `http://localhost:8501`，落在**工作台**：能看到 任务 1 / 数据集 3 / 超限记录 30 / 待重算 0。
2. 看「设备健康状态」：每个监测对象一张卡，卡片上的圆点是测点状态
   （绿 正常、橙 警告、红 严重、紫 数据异常、灰 未设阈值）。演示数据里 CH2 是红色（超阈值）。
3. 看「待办」：按「监测对象 · 通道 · 指标 · 等级 · 时间 · 超限点数」列出超限项，
   **整行可点**，点了直接跳到趋势分析对应位置。
4. 左侧进入「趋势分析」：左侧树选 `CH2`，右侧选指标 → 看到曲线与阈值线；切到「健康评级」页签看全树评级。
5. 左侧进入「数据分析」：选数据集与通道 → 切页签看「① 原始振动曲线 / ② FFT 频谱 / ③ 包络谱」。
6. 左侧进入「健康树配置」：看树结构与每个节点的状态（演示数据 22 个节点：10 正常 / 7 严重 / 5 未设阈值）。

看完想恢复成干净环境：删除 `data\lion.db`（先停程序）后重启，程序会自动建空库。

## 5. 主流程九步

工作台右侧「流程完成度 x/9」对应的就是这九步：

| 步骤 | 在哪做 | 做什么 | 完成标志 |
|---|---|---|---|
| ① 测试任务 | 任务列表 → 新建任务 | 建任务，设为当前任务 | 左侧任务下拉框出现该任务 |
| ② 监测对象 | 监测对象 | 建对象台账（对象类型、部位）、建通道号 | 对象列表里有行，通道挂在对象下 |
| ③ 传感器 | 传感器 | 登记传感器型号/编号，归属到监测对象 | 通道下显示在用的传感器 |
| ④ 指标配置 | 指标配置 | 确认指标码与参数（如 v_RMS 的窗长） | 指标台账有启用的行 |
| ⑤ 数据接入 | 数据接入 | 选采集目录 → 扫描 → 勾批次 → 导入 | 数据集列表新增记录 |
| ⑥ 有效性 | 数据接入导入时 / 数据集管理 | 结构校验 + 有效性状态（有效/部分有效/无效） | 数据集状态不是「待判」 |
| ⑦ 指标计算 | 数据接入（勾「导入时计算指标」） | 按健康树里该通道挂的指标算值 | 趋势分析能画出曲线 |
| ⑧ 阈值 | 阈值设置 | 给「通道 × 指标」填 warn / alert | 健康树该指标不再是灰色 |
| ⑨ 趋势 | 趋势分析 | 看趋势、判级、导出 CSV | 工作台「待办」与健康树状态随时间更新 |

顺序不是死的：可以先配阈值/指标，再导数据；也可以先导一个批次看效果，再补配置。
但**指标要能算，健康树里该通道下必须先挂上指标节点**（第 ⑦ 步的输入）。

## 6. 页面详解

### 6.1 工作台

| 区块 | 内容 |
|---|---|
| 顶部 KPI | 任务数、数据集数、超限记录数、待重算数 |
| 设备健康状态 | 设备分组 → 每个监测对象一张卡：状态色 + 测点（通道）状态点 + 指标数/超限数/待重算 |
| 待办（左） | 振动超限（每行可点进趋势分析）、有效性待判、阈值未设 |
| 任务概览（右） | 任务信息（操作人/创建时间/状态）+ 流程完成度 + 九步流程条 |
| 最近导入 | 默认展开，列最近数据集（编号、名称、通道数、状态、采集时间） |

状态色与文字对应：🟢 正常、🟠 警告、🔴 严重、🟣 数据异常、⚪ 未设阈值。

### 6.2 任务列表

两个页签：**任务列表** / **新建任务**。

- 列表：勾选一行 → 右侧出现「编辑与操作」；可改名称/操作人/状态 → 「保存修改」。
- 「设为当前任务」：把该任务切为全局当前任务（等价于用左侧下拉框切换）。
- 「归档」：任务结束后归档，仍可查看，不再参与日常待办。
- 「进入配置」：直接跳到该任务的健康树配置。
- 删除是软删除，可在回收站恢复。

新建任务只需要名称与操作人；建好后会提示「去监测对象配置设备，再去数据接入导入数据」。

### 6.3 健康树配置

这是整个系统的骨架。层级固定为：

```
测试任务 → 设备 → 监测对象 → 通道 → 监测指标
```

**左侧节点树**

- 每行四列：`＋/－` 展开折叠、设备前的呈现勾选框、节点名称（点一下选中）、右侧状态。
- 设备前的勾选框**只影响呈现**（隐藏该设备子树），不影响数据与判级。
- 展开/折叠只重画树本身，不会把右侧详情一起刷新。

**右侧详情（选中节点后）**

| 页签 | 用途 |
|---|---|
| 节点属性 | 看路径、类型、子节点数量 |
| 监测指标（通道节点） | 选「传感器通道」→「装配通道」；从台账挑「监测对象 + 指标」挂到该通道 |
| 指标参数（指标节点） | 改该指标的算法参数（含高级参数） |
| 子节点 | 新增/删除下级节点 |
| 改名与删除 | 改名、保存额定转速、清除台账引用、删除节点及子树（需二次确认） |

**批量工具（模板导入导出）**

健康树页顶部有个开关「⚙ 批量工具：模板导入导出（低频操作，用时再打开）」，默认关闭（省性能），
需要时打开：

- **导出模板**：可勾「包含阈值配置」，导出 JSON（树结构 + 指标参数 + 阈值 + 台账业务键）。
- **导入模板**：上传 JSON → 先预览（树节点数 / 指标绑定数 / 阈值条数 / 未匹配台账 / 参数差异）
  → 选范围（树结构、指标参数、阈值）与策略（覆盖 / 只补缺失 / 跳过；按生效值搬运 / 只搬固化项 / 只搬覆盖差异）
  → 勾确认 → 「应用模板」。
  - 有未匹配台账时会**阻止导入**（不猜、不错挂），按提示先补台账。
  - 旧版（v1）模板也能读，但会提示并用旧版替换整棵树。

**恢复内置示例树**：空任务时可一键生成 21 个节点的示例结构，用于熟悉界面。

### 6.4 监测对象

两个页签：**对象台账** / **频率参数**。

- 对象台账：勾选一行 → 右侧看详情/改属性（对象类型、部位等）→「保存修改」。
  未选中时显示「＋ 新建对象」。
- 通道设置（对象详情内）：「新增通道」填通道号 →「保存通道」；
  「管理已有通道」可把已有通道改挂到本对象；「已有传感器」把传感器挂到本通道。
- 导出/导入：底部可「⬇ 导出配置」（CSV），也可上传 CSV「确认导入」（适合批量录入台账）。
- 频率参数：录入该对象的特征频率（轴承、齿轮等的理论频率），
  可「⬇ 导出配置」或上传 CSV 批量导入。
  录了之后，数据分析页的频谱图可以直接勾选「台账特征频率」做标记线。

### 6.5 传感器

- 「＋ 新增传感器」：型号、编号、通道号（手输即可；同一通道可登记多台，只留一台在用）。
- 勾选一行 → 可改状态、改「归属监测对象」（保存归属）、保存修改、删除。
- 「批量删除」：勾多行后确认删除。

### 6.6 指标配置

- **指标台账**：勾选一行 → 右侧改参数（算法参数 JSON、单位、是否启用）→「保存修改」。
- **可用算法**：「扫描算法」重新扫描算法目录；「＋ 导入算法（.py）」可导入自定义算法文件
  （支持多选、可勾「覆盖同名文件」）。
- **＋ 新建指标**：选指标码（来自可用算法）、填参数、创建。

指标参数改动会影响后续计算；已经算过的历史值会标记为「待重算」（趋势分析里可一键重算）。

### 6.7 阈值设置

- 筛选：监测对象 / 通道 / 指标 / 实体类型，定位到要改的那一行。
- 在表格里**直接改** `warn` / `alert` 两列 → 点「保存修改」。
- **两列都清空 = 删除该行阈值**，该指标回到继承来的阈值。
- 方向：`上限（越大越差）` 或 `下限（越小越差）`，按指标物理含义选。
- 继承规则（就近覆盖）：

```
指标级  >  通道级  >  对象级  >  设备级  >  任务默认
```

即：只给设备配了阈值，其下所有通道/指标都继承它；某个通道单独配了，就只覆盖这个通道。
右下角「已存阈值」可看全部已配行，「变更历史」可看谁在什么时候改了什么。

> 阈值只影响**判级与显示**，不会改动已算出的指标值。

### 6.8 数据接入

页面流程：**选目录 → 扫描 → 勾批次 → 导入**。

1. **数据目录**：默认是上次用过的目录（首次为安装时配置的演示目录）。
   - 点「📁 浏览目录」打开页面内浏览卡片：`↑ 上级`、盘符、子目录列表，
     选好后「保存」会自动回填并立即扫描；
   - 也可以直接在输入框里粘贴路径。
2. 点「扫描目录」：按**采集批次（子文件夹）**分组，列出每个批次包含的通道文件；
   已有记录的批次会提示「已处理」，重复导入不会产生重复数据集。
3. **扫描结果**：
   - 「全选未处理」「全选」「全不选」快速选择，也可在「要导入的批次」里逐项勾；
   - 「导入时计算指标」默认勾选——算哪些指标由**健康树里该通道下挂的指标节点**决定；
     取消勾选则只落数据集（只做结构级校验）；
   - 点「导入选中批次（N）」开始导入，进度条会显示逐批次进度。
4. 导入完成后：状态提示「已导入 N 个批次」；顶部徽标显示当前任务的数据集/文件/通道节点数。
5. 「指标计算明细」折叠区可查看每个通道将要计算哪些指标（按健康树配置）。
   如果提示「这些通道在健康树里没有指标节点」，说明第 ⑦ 步的前置配置没做。

> 已有同名批次时可勾「覆盖导入」重导（会替换该数据集与其指标值）。

### 6.9 趋势分析

左侧是**健康树**（阈值节点隐藏，避免噪音），右侧两个页签：**趋势** / **健康评级**。

**趋势页签**

1. 左侧点节点：点设备/对象 → 右侧先选「监测对象（一次只看一个对象下的指标）」；
   点通道/指标 → 自动带上对应的指标。
2. 「…的指标（每个子图一条曲线）」多选要看的指标。
3. 「时间窗」：最近 30 天 / 最近 90 天 / 全部。
4. 「横坐标」：北京时间 / 测试点数。
5. 图上带阈值线（warn 橙、alert 红）；超过 2000 点时按 min/max 抽稀（尖峰不会被跳过），
   导出 CSV 始终是全量原始点。
6. 「导出逐点数据 CSV」下载当前曲线明细（含判定与阈值来源）。
7. 「确认重算？」：指标参数改过、历史值为「待重算」时，在这里按指标节点重算并作废旧点位。

**健康评级页签**

- 全树评级表（含子树累计的超限条数与待重算条数）；
- 「超限记录」逐点列出（监测对象 / 采集时间 / 通道 / 指标 / 值 / 单位 / 判定 / 阈值 / 阈值来源）。

### 6.10 数据集管理

- 顶部 KPI：数据集总数、有效数、部分有效数。
- 「数据集列表」勾一行 → 右侧显示该数据集详情：通道文件明细（文件路径、采样率、点数、时长、SHA256）、
  有效性状态。
- 改状态：选「状态」→「保存修改」。
- 删除：「确认删除？」为软删除，可在回收站恢复。删掉的数据集不再参与趋势与统计。
- 「✕ 取消选中」清空选择；空列表时可直接「＋ 去数据接入」。

### 6.11 数据分析

单文件深度分析，三个页签：

| 页签 | 说明 |
|---|---|
| ① 原始振动曲线 | 选「数据集 / 通道」→「纵轴」→「运行绘图」；「导出 CSV」导出当前曲线 |
| ② FFT 频谱 | 选「窗函数」「幅值类型」、是否「去均值」、勾「台账特征频率」→「频谱分析」 |
| ③ 包络谱 | 同上参数 →「运行包络谱」（适合看轴承故障特征频率） |

- 还有「数据集 B / 通道 B」用于**双通道对比**（同一图叠两条曲线，便于对比不同测点）。
- 「＋ 去阈值设置」「＋ 去指标配置」提供快捷跳转。
- 首次进入该页会加载绘图库，需要几秒；之后切换就快了。

### 6.12 数据库备份

- 顶部显示库文件路径与当前大小。
- 「保留份数」：默认 10 份，超出的旧备份自动删除。
- 「立即备份数据库」：在线备份（使用中也能备份），完成后提示文件名、大小、路径。
- 「最近备份」列出备份历史。

备份文件在 `<库文件目录>\backups\`（通常是 `<安装目录>\data\backups\`）。
恢复方式：停止程序 → 把备份文件复制回 `data\lion.db`（先备份当前文件）→ 重启。

### 6.13 回收站

列出所有软删除的记录（对象、数据集、节点等，来自 `deletion_log`）。

- 「恢复选中」：恢复回原位置；
- 「彻底删除」：物理删除，**不可恢复**。

## 7. 判级口径：健康状态怎么算

### 7.1 五种状态

| 状态 | 颜色 | 含义 |
|---|---|---|
| 正常 | 绿 | 指标值在 warn 以内 |
| 警告 | 橙 | 越过 warn，未到 alert |
| 严重 | 红 | 达到/越过 alert |
| 数据异常 | 紫 | 有阈值，但数值不是有限数（NaN / ±Inf），无法判级 |
| 未设阈值 | 灰 | 该指标没有生效阈值（自己没配，上层也没配） |

### 7.2 指标节点

取该指标**最近 5 个有效点**里最严重的一个来判级（只看 1 个点稳定性差）。
由旧参数算出、标记为「待重算」的点不参与判级。

### 7.3 上层节点

设备 / 监测对象 / 通道 / 任务节点：

- 状态 = 子树里**最严重**的那个；
- 「超限 N 条」= 子树内越过的点数之和（不含待重算点）；
- 「待重算 N 条」= 子树内待重算的指标值行数。

### 7.4 为什么阈值配了还是「未设阈值」

按判级口径，指标要**同时满足**「有生效阈值」和「有可判级的有效点」。常见原因：

1. 阈值配在了别的任务下 → 切回当前任务检查；
2. 该指标节点下还没有数据（数据没导入，或导入时没勾「导入时计算指标」）；
3. 所有点都是「待重算」状态 → 去趋势分析页「确认重算」；
4. 阈值行两列都清空了（等于删除）。

## 8. 文件都在哪

以默认安装目录 `C:\LionMonitor` 为例：

| 路径 | 内容 | 说明 |
|---|---|---|
| `data\lion.db` | 数据库（SQLite 单文件） | 任务、树、指标值、阈值、日志表都在这 |
| `data\四通道保存\` | 演示用原始数据（3 个批次 / 12 个 `.dat`） | 删掉后演示数据的波形页会读不到文件 |
| `data\backups\` | 数据库备份 | 「数据库备份」页生成 |
| `logs\lion-monitor.log` | 应用日志（10 MB × 5 轮转） | 排障首选 |
| `logs\server.log` | 服务/终端输出 | Streamlit 启动信息 |
| `logs\launcher.log` | 启动器日志 | 双击没反应时看这里 |
| `logs\selfcheck.log` | 安装/手动自检报告 | 11 项检查结果 |
| `logs\service.log` | 服务注册脚本日志 | NSSM 相关 |
| `.streamlit\config.toml` | 界面与服务配置 | 端口、主题 |
| `runtime\` | 便携 Python 运行时 | 不要手动改 |

**可用的环境变量**（不改代码就能调整行为）：

| 变量 | 作用 |
|---|---|
| `LION_DB` | 指定另一个数据库文件（做多套数据隔离） |
| `LION_SCAN_DIR` | 数据接入页的默认扫描目录 |
| `LION_BACKUP_DIR` | 备份目录 |
| `LION_PROFILE=1` | 在日志里记录每个页面的脚本耗时（排障用） |

## 9. 常见问题

### 9.1 浏览器打不开页面 / 提示「拒绝连接」

1. 确认程序已启动：`logs\launcher.log` 最后一行应为「启动成功，端口 8501」；
2. 检查端口是否被别的程序占用：

   ```bat
   netstat -ano | findstr :8501
   ```

3. 被占用就关掉占用者，或改 `.streamlit\config.toml` 里的 `port` 后重启；
4. 也可以手动跑一次自检（在安装目录）：

   ```bat
   runtime\python.exe tools\selfcheck.py --project-root . --port 8501
   ```

### 9.2 双击 Lion-Monitor 没反应

- 可能已经在运行：启动器检测到已有实例时只会再开浏览器标签页；
- 看 `logs\launcher.log`；若进程存在但页面打不开，关闭启动器窗口后重新双击；
- 极端情况：任务管理器结束 `LionMonitor.exe` 与 `python.exe`（属于本安装目录的那个）后重试。

### 9.2.1 浏览器显示 **Internal Server Error**（白底黑字一行英文）

这是「服务进程活着，但页面渲染失败」，v0.1.0 早先的安装包会出现：**安装/升级时旧实例
没有退出，程序文件被覆盖了一半**。v0.1.1 起安装器会先自动停掉旧实例再覆盖文件，
正常不会再有。

已经撞上了怎么办（按顺序）：

1. 关闭所有 Lion-Monitor 窗口；
2. 装了开机自启时，用管理员 CMD 执行 `sc stop LionMonitor`，
   再执行 `netstat -ano | findstr :8501` 确认端口已释放；
3. 重新运行安装包（升级安装会补齐全部文件）；
4. 仍然不行：开始菜单 → Lion-Monitor →「**收集诊断日志（发给技术支持）**」，
   桌面会生成一个 `LionMonitor-诊断-*.txt`，把那个文件发过来即可。

判断是不是这个问题：该 txt 里「端口与实例」一节会显示 `/_stcore/health → HTTP 200`
但 `/ → HTTP 500`，同时「关键文件完整性」可能标出缺失项。

### 9.3 演示数据的波形/曲线打不开

提示找不到文件，通常是 `data\四通道保存\` 被删或移动了。两种处理：

- 重新安装（会自动补齐演示数据并把路径改到安装目录）；
- 或把自己的采集目录放到任意位置，在「数据接入」里重新扫描导入。

### 9.4 导入成功但趋势没有曲线

按顺序检查：

1. 健康树里该通道下挂指标节点了吗？（健康树配置 → 通道 → 监测指标 → 装配）
2. 导入时勾了「导入时计算指标」吗？（没勾就只入了数据集）
3. 时间窗是不是设成了「最近 30 天」，而数据很旧？换成「全部」；
4. 指标值是否全是「待重算」？去趋势分析「确认重算」。

### 9.5 页面显示「待重算 N 条」

指标参数（算法参数/阈值无关）改过之后，历史值仍是旧参数算的，所以标记待重算：

- 趋势分析 → 选中指标节点 → 「确认重算？」→ 重算；
- 重算会覆盖新值并作废旧点位，需要一点时间（进度条会走）。

### 9.6 中文显示成乱码

- 页面乱码：用 Ctrl+F5 强制刷新页面；
- 命令行输出乱码：先执行 `chcp 65001`，或设置 `set PYTHONIOENCODING=utf-8`；
- 日志文件用支持 UTF-8 的编辑器打开（VS Code / Notepad++）。

### 9.7 想换电脑 / 迁移

1. 老机器：「数据库备份」→「立即备份数据库」；
2. 新机器：安装同版本 → 停止程序 → 用备份文件覆盖 `data\lion.db`；
3. 如果原始数据目录不在安装目录下，把数据目录一并拷过去，并在「数据接入」重新扫描确认路径。

### 9.8 想重置成出厂状态

停程序 → 删除 `data\lion.db`（连同 `-wal`/`-shm`）→ 重启。数据库会自动重建为空库。
演示数据不受影响（在 `data\四通道保存\`）。

## 10. 小技巧

- **换页回到默认状态**：点导航进新页面总是从默认状态开始，不会停在上一页的选中项。
- **树的操作**：`＋/－` 只重画树本身；点名称才会切换右侧详情。
- **设备勾选框**：只是「这次先不看这台设备」，不影响数据。
- **阈值留空**：warn / alert 都清空并保存 = 删除该行，回到继承。
- **表格选中**：多数页面是「勾一行 → 右侧编辑」，改完记得点保存；`✕ 取消选中` 可清空。
- **趋势图抽稀**：图上是抽稀后的点，导出的 CSV 是全量原始点。
- **批量工具**：健康树页顶部的开关默认关闭，需要导入导出模板时再打开。
- **浏览器**：推荐 Edge/Chrome；窗口最大化看趋势更舒服；Ctrl+F5 解决多数「界面没更新」。
- **深色主题**：默认深色，配置在 `.streamlit\config.toml`。

## 11. 术语表

| 术语 | 含义 |
|---|---|
| 测试任务 | 一次监测工作的顶层容器，所有配置与数据都归属某个任务 |
| 健康树 | 任务 → 设备 → 监测对象 → 通道 → 指标的树形结构 |
| 监测对象 | 产线上被测的部件/机构（如「隔膜过辊轴承」） |
| 通道 | 采集通道（CH1–CH4），一个通道可挂多个对象 |
| 指标 | 从振动数据算出的特征量，如 v_RMS（速度有效值）、a_Peak（加速度峰值）、a_RMS |
| 阈值 | warn（预警）/ alert（告警）两条线，可沿树继承 |
| 超限 | 指标值越过 warn 或 alert 的点 |
| 数据集 | 一次采集产生的一组通道文件（一个批次） |
| 待重算 | 指标参数改过后，用旧参数算出的历史值 |
| 特征频率 | 轴承/齿轮等的理论故障频率，用于频谱标记 |
| 包络谱 | 解调后的频谱，擅长发现轴承早期故障 |
